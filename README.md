### 🚀 Selected Projects

#### 🗺️ GeoSpatial API & ArcGIS Publishing Workflow
Built backend workflows for uploading, validating, processing, and publishing spatial data formats such as Shapefile ZIP, GeoPackage, GML, KML, GPX, XML, and GeoJSON into ArcGIS Enterprise. The work involved Python/FastAPI, GDAL/OGR, containerized deployment, Kubernetes configuration, and operational troubleshooting.

#### 📊 GIS Service Monitoring & Splunk Dashboards
Developed health-check and monitoring workflows for GIS services using structured JSON logs, PowerShell/Python automation, and Splunk dashboards. Focus areas included service availability, response time, response size, endpoint status, and operational visibility.

#### 🤖 Minions: Natural Language Control for Robot Swarms
Master’s thesis project at Vrije Universiteit Amsterdam. Designed a system that combines Large Language Models with Behavior Trees to let non-expert users control robotic swarms using natural language commands. The project focused on accessibility, command translation, and safe execution of swarm behaviors.

#### 🧠 EnhanceMatch: AI-Powered Recruitment Matching
Designed and implemented an AI-driven recruitment workflow for Improve to Grow. The system uses intelligent filtering and agent-style logic to match candidate CVs with job applications and was integrated directly into Zoho CRM using Deluge.

#### 🏢 Business Systems & Web Platforms
Built and deployed websites, CRM/ERP setups, and business automation tools using WordPress, Odoo, Zoho CRM, VPS hosting, Docker, and custom integrations.
